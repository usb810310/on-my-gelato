# On My Gelato - 義式冰淇淋專賣店官方網站

現代高級的義式冰淇淋官方網站，展示 12 味精選冰淇淋及品牌理念。

## 功能特色

111完整的 12 味冰淇淋展示
- 🎨 現代高級設計風格（黑色、白色、金色配色）
- 🗺️ 嵌入式 Google 地圖
- 📱 完全響應式設計
- 🔍 分類篩選功能
- 📞 店家資訊和社群媒體連結

## 快速開始

1. 下載 `OnMyGelato.html` 檔案
2. 用任何瀏覽器打開即可
3. 無需安裝任何依賴

## 自訂項目

- 修改社群媒體連結（Instagram、Facebook）
- 更新地址、電話、營業時間
- 調整顏色和字體
- 添加更多冰淇淋口味
